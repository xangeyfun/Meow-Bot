what counts

one successful bot reply adds one meow for the author in that server. blocked channels, rate limited messages, bot authors, and failed sends do not count. totals are all time and are kept separately for each server.

the commands

/stats [user]

shows the user's rank and share in this server, their last meow, the server total, and their global total and rank. leave out the user to check yourself.

/leaderboard

shows the top 10 meowers, the server total, the number of meowers, the server average, and your own rank.

/profile [user]

shows a cross server profile: global total, global rank, servers meowed in, best server, and last meow. it only works inside a server.

/totalmeows

shows the all time global total, the number of servers the bot is in, and the number of people with a meow.

all of these accept hidden:true for a private reply.

how ranks work

rank 1 is the highest count. if two people have the same count, they share the same rank.

when numbers update

a new meow can take a few seconds to appear. server and global totals may take a few minutes to catch up. if a number still looks wrong after that, check the troubleshooting guide.

privacy

stats store discord ids and counts. message text is not stored. the privacy page lists the full set of data and the retention details.
