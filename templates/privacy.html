privacy

what the cat remembers

the short version: ids and counts, not message content. the cat has a small notebook.

what meow bot stores

  • server ids, user ids, and channel ids, so it can count meows and respect channel filters.
  • meow counts and the time of the last meow.
  • server settings, including custom triggers (their patterns and replies), channel filters, and which triggers are on or off.
  • a heartbeat timestamp and basic bot totals for the status page.

what it does not store

  • message content. messages are checked in memory and then discarded.
  • usernames, avatars, email addresses, or payment information.
  • analytics, advertising identifiers, or tracking data.

who can see it

anyone can see server stats with the bot commands. server admins can see and change server settings. the website shows only aggregate totals. the database is not public. the cat does not share its notebook.

removing data

server admins can turn the bot off, remove custom triggers, or clear channel filters at any time. to request deletion of a server's stats, use the support page.
