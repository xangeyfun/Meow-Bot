privacy

what it stores

the short version: ids and counts, not message content.

what meow bot stores

  • server ids and user ids, so it can count meows per server and per user.
  • meow counts and the time of the last meow.
  • server settings, including custom triggers (their patterns and replies) and which triggers are on or off.
  • a heartbeat timestamp and basic bot totals for the status page.

what it does not store

  • message content. messages are checked in memory and then discarded.
  • usernames, avatars, email addresses, or payment information.
  • analytics, advertising identifiers, or tracking data.

who can see it

anyone can see server stats with the bot commands. server admins can see and change server settings. the website shows only aggregate totals. the database is not public.

removing data

server admins can turn the bot off or remove custom triggers at any time. to request deletion of a server's stats, use the support page.
