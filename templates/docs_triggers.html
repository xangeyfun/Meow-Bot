built in triggers

the defaults are on unless an admin turns them off. the woof reply is separate and starts off. built in replies use the shared meow pool.

custom triggers

open /config and use the trigger controls. each server can have up to 25 custom triggers. simple triggers match a word or phrase, are case insensitive, and only fire on word boundaries. advanced triggers are regular expressions, capped at 200 characters and tested before they are saved.

custom triggers are checked before built in triggers. if two custom triggers could match the same message, the first one wins. replies are capped at 500 characters.

simple example

trigger good morning, reply mrrp back. that matches the phrase and not every word inside it.

advanced example

trigger ^mrr+p+$, reply mrrp. this catches longer purr like noises without opening the door to expensive patterns.

channel filters

channel filters decide where the cat can reply. there are three states:

  • no rules: every channel is allowed
  • allow list: once any channel is allowed, only allowed channels are used
  • deny list: denied channels are always blocked, even if they are also allowed

threads count as their own channels. if you want the cat in a thread, add that thread to the allow list. use /config to add, remove, or clear rules.

matching limits

very long messages are only checked for the first 2000 characters. advanced patterns are also time limited, so a bad pattern cannot slow down the bot.

custom text is never saved to the database. only trigger patterns and replies are stored. read the privacy page for the full data picture.
