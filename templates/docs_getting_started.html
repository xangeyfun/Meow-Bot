invite the cat

add meow bot to your server with the invite button below. the bot needs to read messages, send messages, and use slash commands. the public bot is already set up for this.

add to discord

say meow

when the bot sees a meow like message, it replies with a random meow and adds one to the count. punctuation and emoticons are fine. all of these are built in:

  • meow, mreow, mew, mrow, mrrp, nya, and purr
  • longer versions such as meooooow
  • the optional woof trigger, which is off by default

the commands you will use most

/help lists everything. /stats shows your server rank and global total. /leaderboard shows the top meowers in the server. /profile follows you across servers.

every command replies in chat by default. add hidden:true when you want the reply only visible to you.

server settings

server admins can open /config to toggle built in triggers, add custom replies, and choose which channels the cat may use. it requires the manage server permission.

good to know: the cat ignores bots and webhooks. a successful reply is what counts toward stats.
