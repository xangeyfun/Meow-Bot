the bot does not reply

  1. check /ping and the status page.
  2. open /config and confirm the bot is on.
  3. check channel filters. a thread needs its own allow rule.
  4. if you expected a woof, turn on the woof trigger. it starts off.
  5. check the rate limit. the bot sends at most 5 replies per 5 seconds in a channel.
  6. confirm the bot can read messages and send messages in that channel.

slash commands are missing

invite the bot again with the applications.commands scope. discord can take a few minutes to show new commands after an update.

a custom trigger will not save

  • the server already has 25 custom triggers
  • the pattern is empty, too long, or the same as an existing trigger
  • the reply is empty or longer than 500 characters
  • an advanced pattern was rejected by the regex test

stats look stale

counts update every few seconds. the number of servers and meowers can take a few minutes to catch up.

the website shows an older count

wait a few seconds and refresh the page. the website updates on a short delay.

still stuck

open an issue on github or use the support page. include what you tried and any error text.
